# ATIVIDADE-AVALIATIVA-2-SEMETRE-
Para te ajudar a dominar a linguagem do desenvolvimento web, preparei uma lista explicando as principais gírias, jargões e termos técnicos que aparecem no código do seu portfólio.

Entender esses termos é fundamental para mandar bem nas aulas do SENAI e se comunicar como um desenvolvedor profissional no mercado.

🌐 Termos de Estrutura e Layout
container (Contêiner): É uma gíria e técnica de layout para definir uma "caixa" invisível que limita a largura máxima do conteúdo na tela. Ela serve para o seu texto não ficar colado nas bordas do monitor em telas muito grandes, mantendo tudo centralizado e alinhado.

hero (ou Hero Section): No web design, a "seção hero" é o primeiro bloco que o usuário vê ao entrar no site (aquela introdução com o seu nome, "Olá mundo", etc.). É a parte principal, que geralmente ocupa a tela inteira e precisa chamar a atenção.

navbar (Navigation Bar): Abreviação de Barra de Navegação. É o menu do seu site (onde ficam os links "Sobre", "Habilidades" e "Projetos").

nav-links: Gíria para os links/botões que ficam dentro do menu de navegação.

grid (Malha/Grade): É um sistema de layout do CSS (display: grid) que divide a tela em linhas e colunas, como uma tabela invisível. Você usou no código para fazer os cartões de habilidades e projetos ficarem perfeitamente organizados lado a lado.

card (Cartão): Bloco visual que agrupa informações sobre um único assunto (como cada caixinha de habilidade ou o bloco do projeto do restaurante).

🎨 Termos de Estilo e CSS
padding (Espaçamento interno): É a distância entre o conteúdo (texto, por exemplo) e a borda do elemento onde ele está. Pense nisso como a "margem de segurança" interna de uma caixa para o texto não ficar sufocado.

bg ou bg-alt (Background): Abreviação direta de Background (Plano de fundo). O bg-alt é uma gíria comum para "Background Alternativo", usado para mudar a cor de fundo de uma seção para outra, criando contraste na leitura do site.

responsive (Responsivo): É a capacidade do site de "se adaptar" e mudar de formato dependendo do tamanho da tela (computador, tablet ou celular) sem quebrar o layout.

hover (Passar o mouse): É o estado de um elemento quando o usuário posiciona o ponteiro do mouse sobre ele. No CSS, usamos para mudar a cor de um botão ou link, indicando que ele é clicável.

reset (Reinicialização): É o bloco de código no início do CSS (com o símbolo *) usado para limpar as margens e espaçamentos padrão que os navegadores (Chrome, Edge, Safari) já trazem de fábrica, permitindo que você controle o design do zero.

🛠️ Termos de Programação e Tecnologia
DOM (Document Object Model): É a estrutura de árvore do seu HTML que o navegador cria para entender a página. Quando você usa JavaScript para alterar um texto ou abrir um menu no site, você está "manipulando o DOM".

POO (Programação Orientada a Objetos): Um dos paradigmas de programação mais importantes do mercado (muito forte em Java e C#). É a prática de estruturar o seu código simulando objetos do mundo real (com propriedades e ações).

CRUD: Sigla para Create (Criar), Read (Ler/Consultar), Update (Atualizar) e Delete (Deletar). É a gíria para qualquer sistema básico que faz essas quatro operações em um banco de dados (como o seu sistema escolar do SENAI).

tag (Etiqueta): Os comandos do HTML que ficam entre os sinais de menor e maior (ex: <header>, p, <a>). Elas servem para dizer ao navegador o que cada pedaço de texto significa.

tech-tag (Etiqueta de tecnologia): No contexto de portfólios, é aquela pequena marcação visual usada para indicar quais tecnologias foram usadas no projeto (como o balãozinho escrito "HTML / CSS" no card do restaurante).
